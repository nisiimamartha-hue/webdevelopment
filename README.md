 1. What is the assignment asking you to do?

You need to build a console (terminal) program using JavaScript and Node.js.

 It does not have a visual website design or buttons. It runs entirely inside your command prompt or terminal using text.
You can choose any topic you like (e.g., a simple banking app, student grade calculator, or shopping cart system).
 2. Mandatory Code Requirements

Your code must include these core JavaScript components:

At least 3 Functions: Separate pieces of code that carry out specific tasks (e.g., `calculateTotal()`, `addGrade()`, `applyDiscount()`).


Conditional Statements (`if`, `else if`, `else`):** Used for making decisions in code (e.g., checking if a score passes or fails, or if a balance is sufficient for withdrawal).


At least 1 Loop (`for`, `while`, or `do...while`): Used to repeat actions (e.g., asking for student marks repeatedly until done, or displaying a list of items).


User Input / Interaction:** Uses Node.js (`readline` module) to ask the user questions and accept keyboard inputs

 3. Documentation & Comments

Your file must contain comments (`//` or `/* ... */`) explaining two things:

1. At the top of the file:** An overview of what the app does, how to open/run it with Node.js (`node filename.js`), and instructions on how to use it.


2. Throughout the code:** Explanations of what key sections, functions, and loops are doing.

 4. How to Submit

save your solution as a single `.js` file named using your UCU Access Number (for example: `A93044.js`).
